## 3. 评测协议

guidance 1（关CFG），binomial5，每个ckpt 200局 = 4类×50局：`none`（无扰动）、`cov_only`（遮挡）、`inv_only`、`inv_cov`。所有模型用同一协议与同一组episode种子，因此可以按episode配对比较。

每个run目录内：
- `metrics_summary.txt` / `metrics_summary.json`：总表与分类别SR、LSCR
- `<类别>/per_episode.jsonl`：逐episode结果（配对检验用这个）
- `summary.log`：协议审计；`execution.json`、`generalization_catalog.json`
- 同级 `<run>.terminal.log`：worker日志。mask生效判据：出现 `Attention backend selected: flash2 (... causal=False, varlen=True ...)`

模型目录（run的上两级）里 `policy.g1.yaml` 是本次所用策略文件，含 `worldact_root`（mask模型必须指向 `Bench2Dex-Pointflow-fk-mask` 运行时）。

## 5. 必须知道的限制

1. **PF/FK分支梯度未跨卡同步**：`pointflow_branch`、`fk_branch` 在FSDP包装后安装，FSDP不对其梯度all-reduce，8卡各练一份，ckpt只存rank0那份。上表除raw/raw_mix外全部受影响。修复开关 `model.config.sync_plain_param_grads`（主仓库 `047dd24`，默认关），以上模型都没开。
2. **每个变体只有1个训练run、1个任务（task21只有基线与两组mix）**。同配置只换种子，task27合并SR就差3.4 pp（nolocal 53.8 vs seed43 57.1），单点最多差6.5 pp。同一run的25/30/35/40k高度相关，合并4点不能当800个独立样本；把它们当独立样本的Fisher/McNemar p值偏乐观。
3. 评测本身的随机性：task27 mix_f25i15 40k原样重测 66.0→64.0。
4. 续训模型（ft40/ft4k/20k一轮）已废弃并删除，不要引用。
